# Accounts, subscriptions, and usage

Last verified: July 13, 2026. Provider plans change; check the linked live pages before purchasing or publishing commercial work.

| Service | Minimum for a test | Recommended for the course | Commercial note |
|---|---|---|---|
| GitHub | Free account | Free account | Repository access only |
| Codex | Eligible ChatGPT Free login | Plus or Pro for sustained usage | Limits vary by plan |
| Grok guided mode | Grok free access when available | SuperGrok for higher limits | Preserve Grok provenance and watermarking |
| Grok automatic mode | xAI API key with billing | Controlled xAI API budget | SuperGrok does not replace xAI API billing |
| Fish Audio | Personal API key and `s2.1-pro-free` while available | Paid plan when SLA or commercial terms require it | Announced free window runs through the end of July 2026 and is not permanent |
| ElevenLabs fallback | Free API plan with 10,000 credits monthly | Starter or higher for cloning or commercial licensing | Free output is for non-commercial use with attribution |
| Claude | Not required | Optional for existing users | Bundled Codex scripting is sufficient |

ElevenLabs is not required when Fish Audio is available. It is the configured fallback for outages, quota, and unavailable Fish entitlements. Never use fallback to bypass a policy, consent, or licensing rejection.
