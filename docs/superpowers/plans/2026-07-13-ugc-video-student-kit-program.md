# UGC Video Student Kit Program Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use $subagent-driven-development (recommended) or $executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a public student kit that bootstraps supported Macs and Windows/WSL machines, runs the checkpointed UGC pipeline, falls back from Fish Audio to ElevenLabs, and verifies the final media.

**Architecture:** Deliver the product in three independently testable increments. Foundation first establishes packaging, configuration, diagnostics, platform installers, and local Whisper redundancy; pipeline then adds cloud adapters, resumable orchestration, voice fitting, and rendering; release hardening finally adds the student experience, security controls, CI, licensing guidance, and publication gates.

**Tech Stack:** Python 3.11, `uv`, Typer, Rich, Pydantic, HTTPX, NumPy/SciPy, FFmpeg/FFprobe, Rubber Band, whisper.cpp, Faster-Whisper, MLX Whisper on Apple Silicon, OpenAI Whisper in WSL, Node.js, Remotion, Codex CLI, Grok CLI, Fish Audio API, ElevenLabs SDK, xAI Imagine API, PowerShell, Bash, GitHub Actions.

## Integration lane

The primary agent owns:

- Shared type and configuration changes.
- Review of every task-level commit before integration.
- `main` branch merges.
- Cross-plan regression commands.
- Clean-machine acceptance evidence.
- The final publication decision and rollback record.

Parallel workers must not modify the same shared contract simultaneously. When a contract change is necessary, pause dependent work, update the design/plan if material, merge the contract change, then resume.

## Commit policy

- One coherent commit per completed task.
- Tests must be green before each task commit.
- Generated audio/video, credentials, `.env`, provider sessions, model weights, and local output directories must never enter Git.
- Vendor CLI binaries and Whisper model files are downloaded during setup, not committed.
- Commit messages use `build:`, `feat:`, `fix:`, `test:`, `docs:`, or `ci:` prefixes.

## Publication gate

Do not create the public remote or GitHub release until:

- Supported clean-machine acceptance is recorded for Apple Silicon and Windows 11/WSL2.
- `ugc-video demo` completes on both targets.
- Fish primary and ElevenLabs fallback smoke tests pass with disposable student-style credentials.
- Secret and Git-history scans pass.
- README subscription claims are rechecked against the linked live vendor pages.
- Rollback and uninstall instructions are tested.
- The user explicitly approves deployment.
